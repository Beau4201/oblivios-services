# Code of conduct

ObliviOS is a small project run by one person. The rules are short.

- Be civil. Argue about the work, not about the person who did it.
- No harassment, no threats, no hate speech, and no sharing of other people's private information.
- Keep an issue to this repository: a defect, a wrong statement, a question about what is published, a correction.
- Disagreement is welcome. A claim about security or privacy, mine included, is expected to name the threat it answers.

A comment that breaks these rules is hidden or deleted, and a person who keeps breaking them is blocked. The maintainer decides and says why when asked.

To report behaviour that you do not want to raise in public, write to the contact in `SECURITY.md`.
